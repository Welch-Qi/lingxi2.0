# 灵犀 2.0 · 字段级数据字典 · 08 市场情报（L2：`intel_`）

> **版本**：V0.1 草案（待评审）｜2026-10-12｜任务：M0000-008（Wave 3 六域补全）
> **前置**：公共列、来源标记列、类型口径、枚举 `E{n}`、追加型豁免见《字段级数据字典-00-公共约定.md》。
> **来源依据**：《功能清单V2.1》市场情报 / 商机发现（BO-MKT-09~13）；Wave 0 裁决 ②（见 00 §七）。
> **定位**：情报域**不落原始事实表**——外部明细一律落 L1 `dt_raw_*` / `dt_hot_keyword` / `dt_trend_keyword`（公域、可重建、白名单免租），`intel_` 只出**派生视图 + 租户级监控/报告**。视图 `租户=否（透传底层 RLS）`，落库表为**租户私域**（`租户=是｜RLS=是`）。
> **Wave 0 裁决 ②**：「外部明细落 L1 还是 intel」→ 原始明细落 L1、`intel` 只出视图不落事实表。本文件严格遵循，**不重复建 `dt_raw_*`**。

## 一、派生视图（只读，不落事实表）

> 视图把 L1 公域原始 + 趋势词聚合成"情报语义"，供前端情报页与工作台消费；口径可随 `dt_metric_definition` 重建。**视图自身不新增物理列**，字段即底层投影/聚合结果。

### 1.1 `v_intel_search_trend` · 搜索趋势视图
> ← `dt_raw_search_trend`（02 §3.3）
| 输出列 | 来源 | 说明 |
|---|---|---|
| `keyword` | `dt_raw_search_trend.keyword` | 关键词 |
| `geo` | `.geo` | 地区（ISO-3166 alpha-2） |
| `category_code` | `.category_code` | 行业/品类 |
| `period_start` | `.period_start` | 趋势周期起点 |
| `period_gran` | `.period_gran`（**E44**） | 粒度（日/周/月） |
| `index_value` | `.index_value` | 搜索指数值 |
| `mom_growth` | 派生：`index_value` 环比 | 热度环比增速（窗口函数 `lag()`，不落列） |

> 按 `(keyword, geo, period_start)` 聚合；分区裁剪靠底层 `period_start`。

### 1.4 `v_intel_trade_flow` · 贸易流向视图
> ← `dt_raw_customs`（02 §3.1），按 `hs_code × country_pair × trade_date` 聚合
| 输出列 | 来源 | 说明 |
|---|---|---|
| `hs_code` | `dt_raw_customs.hs_code` | 海关编码（关联 `prd_product.hs_code`） |
| `country_pair` | `.country_pair` | 出口国-进口国 |
| `counterparty_role` | `.counterparty_role`（**E20**） | 采购商 / 供应商 |
| `period` | 派生：`date_trunc(trade_date)` | 月度聚合 |

> **安全**：底层 `dt_raw_*` 为公域白名单表（无 RLS），视图透传；租户私域过滤在应用层按 `hs_code`/`industry_code` 订阅范围裁剪，不在视图硬编码 `tenant_id`。

## 二、监控关键词（`intel_keyword_watch`）

### 2.1 `intel_keyword_watch` · 监控关键词清单〔P1〕
> 租户:是｜RLS:是｜来源:否｜分区:否　`[P1]`（BO-MKT-09，本 Wave 登记并按说明书给关键字段）
> 租户自主圈定要盯的词，热度突变触发预警进工作台待办。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `keyword` | `VARCHAR(128)` | `NOT NULL` | 监控词 |
| `industry_code` | `VARCHAR(64)` | | 行业（缩小匹配范围） |
| `region` | `CHAR(2)` | | 目标市场（ISO-3166 alpha-2） |
| `watch_type` | `VARCHAR(16)` | `NOT NULL` | 热搜 / 上升 / 竞品 / 品类（值集待产品确认，登记 `sys_dict`） |
| `threshold_pct` | `SMALLINT` | | 预警阈值（环比涨幅 %，命中触发 `lx.intel.keyword.changed`） |
| `notify_channel` | `VARCHAR(64)` | | 推送渠道（站内/邮件…，登记） |
| `owner_user_id` | `BIGINT` | | 负责人 → `sys_user.id` |
| `is_active` | `BOOLEAN` | `NOT NULL default true` | 是否启用 |

索引：`UNIQUE(tenant_id, keyword, industry_code, region) WHERE is_deleted=0`、`(owner_user_id, is_active)`。

## 三、机会与容量报告（`intel_opportunity_report`）

### 3.1 `intel_opportunity_report` · 产品机会 / 市场容量报告
> 租户:是｜RLS:是｜来源:是（智能体生成，BO-MKT-10/11/13）｜分区:否
> 报告为**快照型**——生成时把趋势/贸易/竞品数据凝固成 JSONB，避免底层公域表重建后历史报告漂移。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `biz_code` | `VARCHAR(64)` | `NOT NULL` | 报告编号（`IR-2026Q3-01`） |
| `title` | `JSONB` | `NOT NULL` | 报告标题（多语言） |
| `report_type` | `VARCHAR(16)` | `NOT NULL` | 机会发现 / 市场容量 / 竞品分析（值集登记 `sys_dict`） |
| `product_id` | `BIGINT` | | 关联商品 → `prd_product.id`（可空，品类级报告无单品） |
| `industry_code` | `VARCHAR(64)` | | 行业 |
| `region_scope` | `JSONB` | | 覆盖市场数组（`["DE","FR"]`…） |
| `period_start` | `DATE` | | 统计区间起 |
| `period_end` | `DATE` | | 统计区间止 |
| `summary` | `JSONB` | | 结论摘要（容量/增速/机会点，多语言） |
| `detail_json` | `JSONB` | `NOT NULL` | 报告正文快照（趋势曲线、贸易流向、竞品矩阵等凝固结果） |
| `status` | `VARCHAR(16)` | `NOT NULL default 'GENERATING'` | **E73**（生成中 / 就绪 / 归档） |
| `generated_at` | `TIMESTAMPTZ` | | 生成完成时刻 |

索引：`UNIQUE(tenant_id, biz_code) WHERE is_deleted=0`、`(report_type, status)`、`(product_id)`、`(period_start, period_end)`。
> **来源标记**：智能体生成时 `source_type=AGENT` + `source_agent_code`（**E77** `AG02_MARKET`）+ `source_task_id`（→ `ag_task`，字段级见 10 文件）；人工触发/编辑保留 `HUMAN`。报告正文的向量/检索由元枢 semantic 引擎（`com.yuanshu.sem`）产出，本侧仅存 `detail_json` 快照，不建向量表。

## 五、跨域与归口约束

- **底层数据引用**：`intel` 视图全部投影自 L1 `dt_raw_*`/`dt_hot_keyword`/`dt_trend_keyword`（02），**情报域不自建事实/原始表**（Wave 0 ②）。
- **主数据引用**：`intel_opportunity_report.product_id` → `prd_product`；`owner_user_id` → `sys_user`；`hs_code` 与 `prd_product.hs_code` 同码。
- **下游联动**：机会报告结论可推动 `cus_opportunity` 立项；关键词预警经 `sys_message`/`v_wb_todo`（12 文件）进工作台待办。
- **归口元枢**：报告正文的向量化/语义检索由元枢 `com.yuanshu.sem` 产出，本侧存快照 `detail_json`，不建向量表、不建引擎表。
- **事件命名**：灵犀侧一律 `lx.*`（硬约束 3）；元枢治理事件 `ys.*` 不在本文件登记。
