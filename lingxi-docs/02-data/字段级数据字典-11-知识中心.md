# 灵犀 2.0 · 字段级数据字典 · 11 知识中心（L2：`kc_`·仅内容面）

> **版本**：V0.1 草案（待评审）｜2026-10-12｜任务：M0000-008（Wave 3 六域补全）
> **前置**：公共列、来源标记列、类型口径、枚举 `E{n}`、追加型豁免见《字段级数据字典-00-公共约定.md》。
> **来源依据**：《功能清单V2.1》知识中心（KC-07~15 内容面：模板/话术/问答）。
> **定位**：本域**只承载知识内容面**——模板、话术、问答对及其调用台账，供智能体与营销/邮件引用。均为租户私域（`租户=是｜RLS=是`）；内容多语言正文走 `JSONB`。
> **🔴 归口边界（硬约束）**：`KC-01~06` **知识引擎框架 / 文档托管 / 向量检索**归 **元枢 `yuanshu-semantic`（`com.yuanshu.sem`）**；`KC-16~19/22` **提示词库**归元枢。本侧**不建引擎/文档/提示词表**，`kc_*` 内容行的向量化仅存 `embedding_ref` 逻辑引用（向量由元枢引擎产出）。

## 一、模板（`kc_template`）

### 1.1 `kc_template` · 内容模板〔P0-A〕
> 租户:是｜RLS:是｜来源:否｜分区:否　（KC-07~09）
> 营销开发信 / 报价单 / 合同 / 跟进邮件等模板；被 `mkg_email_campaign.template_id` 引用（见 07 §5.1）。多语言正文 `JSONB`。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `biz_code` | `VARCHAR(64)` | `NOT NULL` | 模板编号（业务键） |
| `name` | `JSONB` | `NOT NULL` | 模板名（多语言） |
| `content_type` | `VARCHAR(16)` | `NOT NULL default 'TEMPLATE'` | **E79**（内容类别） |
| `scene` | `VARCHAR(24)` | `NOT NULL` | **E80**（开发信/报价/合同/跟进/售后/其他） |
| `industry_code` | `VARCHAR(64)` | | 行业分类 |
| `lang` | `VARCHAR(8)` | `NOT NULL` | 主语种短码（多语言正文按 locale 存 `body_json`，或每语种一行——见待决策） |
| `body_json` | `JSONB` | `NOT NULL` | 模板正文（含变量占位 `{{customer_name}}` 等，多语言） |
| `variables_json` | `JSONB` | | 可填变量清单（名/类型/必填） |
| `category_code` | `VARCHAR(64)` | | 分类（登记 `sys_dict`） |
| `status` | `VARCHAR(16)` | `NOT NULL default 'DRAFT'` | 发布态（复用 **E41** `content_status` `DRAFT/PUBLISHED/OFFLINE`） |
| `content_version` | `INTEGER` | `NOT NULL default 1` | 内容版本（P1-2，非乐观锁 `version`） |
| `owner_user_id` | `BIGINT` | | 负责人 |
| `embedding_ref` | `VARCHAR(128)` | | 🔴 向量引用（元枢 `com.yuanshu.sem` 产出，本侧不存向量） |

索引：`UNIQUE(tenant_id, biz_code) WHERE is_deleted=0`、`(scene, status)`、`(industry_code)`、`(content_type)`。

## 六、跨域与归口约束

- **被引用**：`mkg_email_campaign.template_id` → `kc_template.id`（07 §5.1，KC-09/BO-MKG-15）；智能体应答引用 `kc_script`/`kc_qa`（经 `ag_task`）。
- **多语言**：正文一律 `JSONB`（00 §四）；素材/图片复用 `prd_material`/`sys_file`，不在本域重复上传。
- **🔴 归口元枢（不建表）**：`embedding_ref` 向量由元枢 `com.yuanshu.sem` 引擎产出与检索；`KC-01~06` 知识引擎框架、文档托管、`KC-16~19/22` 提示词库均在元枢，本侧无引擎/文档/向量/提示词表，仅存 `embedding_ref` 逻辑引用。
- **事件联动**：`kc_*.status` 转 `PUBLISHED` 发 `lx.kc.template.published`，供元枢侧相关提示词/RAG 缓存失效（技术规约 §3.5 F6）。
- **事件命名**：灵犀侧一律 `lx.kc.*`（硬约束 3）。

## 七、待决策项（留人工裁决）

1. **多语言正文建模粒度**：`kc_*` 用「单行 `body_json` 按 locale 合并」（本草案）还是「每语种一行」（与 07 `mkg_content.lang` 保持一致）——需与营销域内容口径统一裁决。
2. **`content_version` 与发布流**：模板改版是就地升 `content_version` 还是建历史版本表 `kc_template_version`——影响调用台账可追溯性，待确认。
3. **🔴 `embedding_ref` 一致性**：向量在元枢、内容在灵犀，内容更新后向量重算的触发与时序（是否随 `lx.kc.template.published`）待与元枢 `com.yuanshu.sem` 对齐。
