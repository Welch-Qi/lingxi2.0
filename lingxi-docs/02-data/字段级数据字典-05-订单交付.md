# 灵犀 2.0 · 字段级数据字典 · 05 订单交付（L2：`ord_`）

> **版本**：V0.2（2026-09-13 评审回写）
> **前置**：公共列、来源标记列、类型口径、枚举 `E{n}` 见《字段级数据字典-00-公共约定.md》。
> **定位**：订单交付为**租户私域**，所有表 `租户=是｜RLS=是`。订单可由智能体从商机/询盘生成 → `来源=是`。
> **金额口径**：全部 `BIGINT` 最小货币单位；单据存 `currency` + `exchange_rate` 快照 + 折算本位币金额（④）。
> **主数据引用**：商品只存 `product_id` + 成交快照（品名/规格/单价），不回查 `prd_`。

## 一、订单主表与明细

### 1.1 `ord_order` · 订单
> 来源:是｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `order_no` | `VARCHAR(64)` | `NOT NULL` | 订单业务键 |
| `customer_id` | `BIGINT` | `NOT NULL` | → `cus_customer.id` |
| `contact_id` | `BIGINT` | | 下单联系人 |
| `opportunity_id` | `BIGINT` | | 赢单来源商机 |
| `owner_user_id` | `BIGINT` | `NOT NULL` | 归属销售 → 数据权限 |
| `region_code` | `VARCHAR(32)` | | 数据权限维度 |
| `market_code` | `VARCHAR(32)` | | 数据权限维度 |
| `currency` | `CHAR(3)` | `NOT NULL` | 下单币种 |
| `exchange_rate` | `NUMERIC(18,8)` | `NOT NULL` | 成交时点快照汇率 ④ |
| `amount_total_min` | `BIGINT` | `NOT NULL` | 订单总额（原币，最小单位） |
| `amount_base_min` | `BIGINT` | `NOT NULL` | 折算本位币总额（快照） |
| `order_date` | `DATE` | `NOT NULL` | 下单日 |
| `delivery_date` | `DATE` | | 约定交付日 |
| `status` | `VARCHAR(24)` | `NOT NULL` | E33 |
| `pay_status` | `VARCHAR(16)` | `NOT NULL` | E34 |
| `remark` | `TEXT` | | |

索引：`UNIQUE(tenant_id, order_no) WHERE is_deleted=0`、`(customer_id)`、`(status, pay_status)`、`(owner_user_id)`、`(order_date)`。

### 1.2 `ord_order_item` · 订单明细行
> 来源:否（随主单）｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `order_id` | `BIGINT` | `NOT NULL` | → `ord_order.id` |
| `line_no` | `SMALLINT` | `NOT NULL` | 行号 |
| `product_id` | `BIGINT` | `NOT NULL` | → `prd_product.id` |
| `sku_snap` | `VARCHAR(64)` | `NOT NULL` | 成交 SKU 快照 |
| `product_name_snap` | `VARCHAR(256)` | `NOT NULL` | 品名快照 |
| `spec_snap_json` | `JSONB` | | 规格快照 |
| `qty` | `BIGINT` | `NOT NULL` | 数量 |
| `unit` | `VARCHAR(16)` | `NOT NULL` | |
| `unit_price_min` | `BIGINT` | `NOT NULL` | 单价（最小单位，原币） |
| `amount_min` | `BIGINT` | `NOT NULL` | 行金额 = `round(qty × unit_price_min × (1 - discount_rate))`（含折扣，P1-6） |
| `discount_rate` | `NUMERIC(4,2)` | | 折扣率 |

索引：`UNIQUE(order_id, line_no)`、`(product_id)`。
> `qty` 用 `BIGINT` 计数；金额行不重复存币种，币种取主单 `currency`。

## 二、OTD 交付节点（Order-To-Delivery）

### 2.1 `ord_otd_node_def` · 节点模板（租户可配）
> 来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `node_code` | `VARCHAR(32)` | `NOT NULL` | E35（默认模板来自 `cc` E13 `OTD_DEFAULT`） |
| `name_i18n` | `JSONB` | `NOT NULL` | |
| `seq` | `SMALLINT` | `NOT NULL` | 节点顺序 |
| `std_duration_days` | `SMALLINT` | | 标准工期 |
| `alert_lead_days` | `SMALLINT` | | 延期预警提前天数 |
| `is_enabled` | `BOOLEAN` | `NOT NULL default true` | |

索引：`UNIQUE(tenant_id, node_code) WHERE is_deleted=0`、`(tenant_id, seq)`。
> 下单时按启用的节点定义**实例化**为该订单的 `ord_otd_node` 行（模板→实例）。

### 2.2 `ord_otd_node` · 订单节点实例
> 来源:是（状态可被智能体回填）｜分区:否

|---|---|---|---|

| `node_def_id` | `BIGINT` | `NOT NULL` | → `ord_otd_node_def.id` |
| `node_code` | `VARCHAR(32)` | `NOT NULL` | E35（快照，防模板变更影响历史） |
| `seq` | `SMALLINT` | `NOT NULL` | |
| `planned_date` | `DATE` | | 计划完成日 |
| `actual_date` | `DATE` | | 实际完成日 |
| `status` | `VARCHAR(16)` | `NOT NULL` | E36 |
| `is_delayed` | `BOOLEAN` | `NOT NULL default false` | 派生标记（超计划未完） |
| `owner_user_id` | `BIGINT` | | 节点负责人 |
| `note` | `TEXT` | | |

索引：`UNIQUE(order_id, node_code)`、`(status, planned_date)`（延期扫描）、`(order_id, seq)`。
> 节点完成/延期迁移事件：`lx.ord.otd.node_completed/delayed`；`is_delayed` 由 `data-jobs` 定时重算（派生）。

### 3.2 `ord_payment` · 收款计划/流水　🔴 支付红线

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `biz_code` | `VARCHAR(64)` | `NOT NULL` | 收付款单号 |

| `amount_min` | `BIGINT` | `NOT NULL` | 金额（原币，最小单位） |
| `currency` | `CHAR(3)` | `NOT NULL` | |
| `exchange_rate` | `NUMERIC(18,8)` | | 快照汇率 |

## 四、状态机与事件落点

| 对象 | 状态字段 | 枚举 | 迁移事件 |
|---|---|---|---|
| 订单 | `ord_order.status` | E33 | `lx.ord.order.confirmed/status_changed` |
| OTD 节点 | `ord_otd_node.status` | E36 | `lx.ord.otd.node_completed/delayed` |
| 收付款 | `ord_payment.status` | E34 | `lx.ord.payment.received/settled` |

> 订单状态推进触发跨模块事件（如确认→生产、发运→通知），经 `sys_outbox` 投递，消费方幂等。
