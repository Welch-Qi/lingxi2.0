# 灵犀 2.0 · 字段级数据字典 · 02 数据底座（L1：`dt_`）

> **版本**：V0.8（2026-10-20 **唯一约束冲突修正落地**：新增 Flyway `V202610201100__dt_fix_account_asset_unique_constraint.sql`，移除 `dt_account_asset` 冗余表级 `UNIQUE (tenant_id, asset_code)` 约束，保留部分唯一索引 `uk_dt_account_asset_active ... > **前置**：公共列、来源标记列、类型口径、枚举 `E{n}`、白名单清单、追加型豁免见《字段级数据字典-00-公共约定.md》。
> **定位**：L1 是壁垒层。**公域原始明细**（`dt_raw_*` / `dt_hot_keyword` / `dt_trend_keyword`）跨租户共享；**实体主档按租户分档**（承 ADR-0004 V2·2026-10-14），跨租户消歧归元枢语义本体；私域沉淀落 `cus_`（见 03）。
> **裁决（Wave 0）**：② 外部明细落 L1 已采纳（本文件）；⑤ 实体中心隔离模型属红线，**ADR-0004 V2 已采纳（2026-10-14）**——方案 A1（实体主档按租户分档 · 顺代码），全部实体表均为租户私域，跨租户消歧归元枢（见下 §二 P0-2 指针）。
