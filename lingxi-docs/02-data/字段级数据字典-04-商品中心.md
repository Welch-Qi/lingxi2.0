# 灵犀 2.0 · 字段级数据字典 · 04 商品中心（L2：`prd_`）

> **版本**：V0.2（2026-09-13 评审回写）
> **前置**：公共列、类型口径、枚举 `E{n}` 见《字段级数据字典-00-公共约定.md》。
> **定位**：商品中心为**租户私域**，所有表 `租户=是｜RLS=是`。商品/素材可被智能体生成或回填 → `来源=是`。
> **多语言**：品名/属性名/素材标题一律 `JSONB`（`name_i18n`），禁止硬编码中文列。

---

## 一、类目与属性（主数据骨架）

### 1.1 `prd_category` · 商品类目
> 来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `cat_code` | `VARCHAR(64)` | `NOT NULL` | 类目编码 |
| `parent_id` | `BIGINT` | | 树形父级，`NULL`=根 |
| `name_i18n` | `JSONB` | `NOT NULL` | 多语言类目名 |
| `path` | `VARCHAR(512)` | `NOT NULL` | 物化路径 `/<id>/<id>/` |
| `level` | `SMALLINT` | `NOT NULL` | |
| `is_leaf` | `BOOLEAN` | `NOT NULL default false` | 叶子挂 SPU |
| `sort` | `INTEGER` | `NOT NULL default 0` | |

索引：`UNIQUE(tenant_id, cat_code) WHERE is_deleted=0`、`(tenant_id, path)`、`(parent_id)`。

### 1.2 `prd_attribute` · 属性定义
> 来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `attr_code` | `VARCHAR(64)` | `NOT NULL` | 属性编码 |
| `name_i18n` | `JSONB` | `NOT NULL` | |
| `value_type` | `VARCHAR(16)` | `NOT NULL` | E31 |
| `unit` | `VARCHAR(16)` | | 计量单位（`NUMBER` 时） |
| `options_json` | `JSONB` | | `ENUM` 候选值（多语言） |
| `category_id` | `BIGINT` | | 适用类目，`NULL`=全局 |
| `is_required` | `BOOLEAN` | `NOT NULL default false` | |
| `sort` | `INTEGER` | `NOT NULL default 0` | |

索引：`UNIQUE(tenant_id, attr_code) WHERE is_deleted=0`、`(category_id)`。

## 二、商品（SPU/SKU）

### 2.1 `prd_product` · 商品（SKU 粒度）
> 来源:是｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `sku` | `VARCHAR(64)` | `NOT NULL` | SKU 业务键 |
| `spu_code` | `VARCHAR(64)` | | SPU 归组 |
| `name_i18n` | `JSONB` | `NOT NULL` | 多语言品名 |
| `category_id` | `BIGINT` | `NOT NULL` | → `prd_category.id`（叶子） |
| `brand` | `VARCHAR(128)` | | |
| `hs_code` | `VARCHAR(16)` | | 海关编码（关联 `dt_raw_customs.hs_code`） |
| `model_no` | `VARCHAR(128)` | | 型号 |
| `origin_country` | `CHAR(2)` | | 原产地 |
| `unit` | `VARCHAR(16)` | | 基本计量单位 |
| `main_image_file_id` | `BIGINT` | | → `sys_file.id` |
| `spec_json` | `JSONB` | | 规格快照（冗余便于列表展示） |
| `status` | `VARCHAR(16)` | `NOT NULL` | E47 |
| `completeness` | `SMALLINT` | | 资料完整度 0-100（派生，见总览§七） |

索引：`UNIQUE(tenant_id, sku) WHERE is_deleted=0`、`(category_id, status)`、`(spu_code)`、`(hs_code)`。
> 属性明细不在此表，走 `prd_product_attribute`（避免 JSONB 大列高频展开）。

### 2.2 `prd_product_attribute` · 商品-属性值
> 来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `product_id` | `BIGINT` | `NOT NULL` | → `prd_product.id` |
| `attribute_id` | `BIGINT` | `NOT NULL` | → `prd_attribute.id` |
| `attr_value` | `VARCHAR(512)` | `NOT NULL` | 值（`ENUM` 存 code，`BOOL` 存 true/false） |
| `attr_value_num` | `NUMERIC(18,6)` | | `value_type=NUMBER` 时冗余数值，供区间筛选/排序（P1-14；需存量回填） |
| `attr_value_i18n` | `JSONB` | | 多语言展示值（可选） |

索引：`UNIQUE(tenant_id, product_id, attribute_id)`、`(attribute_id, attr_value_num)`（数值区间筛选，P1-14；原 `(attribute_id, attr_value)` 字符串比较已替换）。

## 三、素材库

### 3.1 `prd_material` · 素材
> 来源:是｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `material_code` | `VARCHAR(64)` | `NOT NULL` | 素材编码 |
| `product_id` | `BIGINT` | | 关联商品（可空） |
| `file_id` | `BIGINT` | `NOT NULL` | → `sys_file.id`（二进制在对象存储） |
| `material_type` | `VARCHAR(16)` | `NOT NULL` | E32 |
| `title_i18n` | `JSONB` | | 多语言标题 |
| `lang` | `VARCHAR(16)` | | 素材语言 |
| `category` | `VARCHAR(32)` | | 素材分类 |
| `width` | `INTEGER` | | 图片宽（`IMAGE`） |
| `height` | `INTEGER` | | 图片高 |
| `duration_sec` | `INTEGER` | | 视频时长（`VIDEO`） |
| `checksum` | `VARCHAR(64)` | | 内容指纹（去重/秒传） |
| `status` | `VARCHAR(16)` | `NOT NULL` | `DRAFT`/`APPROVED`/`OFFLINE`（对外素材须人审 E 自主度） |

索引：`UNIQUE(tenant_id, material_code) WHERE is_deleted=0`、`(product_id)`、`(material_type, status)`、`(checksum)`。

### 3.2 `prd_material_ref` · 素材引用关系
> 来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `material_id` | `BIGINT` | `NOT NULL` | → `prd_material.id` |
| `ref_type` | `VARCHAR(32)` | `NOT NULL` | E48 |
| `ref_id` | `BIGINT` | `NOT NULL` | 多态引用对象 |
| `usage_count` | `INTEGER` | `NOT NULL default 0` | 引用计数（删素材前校验） |

索引：`UNIQUE(tenant_id, material_id, ref_type, ref_id)`、`(ref_type, ref_id)`。
> 素材标签统一走 `dt_tag_relation`（`target_type=MATERIAL`），本域不建独立标签表。
