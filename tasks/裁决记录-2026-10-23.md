## 三、`object_type` 取值清单（裁决 14）

`dt_knowledge_embedding.object_type` 为 `VARCHAR(32)`（无枚举约束），
本清单取自 **02-data《概念数据模型-实体清单》V0.6** 的实体域划分：

| 取值 | 含义 | 指向 |
|---|---|---|
| `entity_company` | 企业实体 | `dt_entity_company` |
| `entity_contact` | 企业级联系人 | `dt_entity_contact` |
| `document` | 文档（知识条目） | 外部文档 / 文件（`sys_file` 引用） |
| `template` | 内容模板 | `kc_template`（P0-A，§5.1 之后建表） |
| `script` | 标准话术 | `kc_script`（P0-A/B） |
| `qa` | 标准问答对 | `kc_qa`（P0-B） |
| `raw_customs` | 海关明细 | `dt_raw_customs` |
| `raw_company` | 企业库记录 | `dt_raw_company` |

**约束**：
- 检索**不限** `object_type`（默认全量），传入时按取值过滤
- 取值不在清单内 → 返回 `010004`（参数非法），**不静默忽略**
- 清单随实体清单版本演进，增减须同步本文件与 02-data 实体清单
