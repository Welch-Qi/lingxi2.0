# AGENTS.md · yuanshu-data-worker（元枢数据执行进程，一期空缺）

> 总纲见仓库根级 `../AGENTS.md`（本文件冲突时以根级为准）。
> 产品归属：**元枢（数智底座）**——本仓是元枢大数据能力的算法/采集扩展位（三产品归口表 §6.4）。

## 状态：一期空缺

一期数据任务（采集 / 清洗 / 实体消歧 / 指标计算，DT-01~07、GM-01~12）由 `lingxi-server` 内的
`yuanshu/yuanshu-data-jobs` 进程承载（见 ADR-0003）。本仓库为占位，暂不启用。

## 若启用（需先开 ADR）

1. **独立 CI 流水线**：与后端 Java 链路分属两套构建，不得混用同一条流水线。
2. **禁止承载业务逻辑**：业务链路的唯一语言栈是 Java（已确认原则）；本仓只做数据采集与算法。
3. **数据不落地本地**：连云端数据服务，经 SSH 隧道（与后端同一套隧道定义）。
4. 与业务交互一律经 `yuanshu-data` / `yuanshu-semantic` 暴露的 API（`com.yuanshu.dt.api`、
   `com.yuanshu.sem.api`）或事件（元枢治理事件用 `ys.*` 命名空间），禁止直连业务库改数据。
5. **只服务元枢**：产出供灵犀、开物两集群经元枢出口 API 消费；本仓不得直接面向任一集群业务。
