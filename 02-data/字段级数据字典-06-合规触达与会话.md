# 灵犀 2.0 · 字段级数据字典 · 06 合规触达与会话（P0-4 骨架：`svc_` / `mkg_`）

> **版本**：V0.1（P0-4 Wave 1 合规硬缺口最小骨架）
> **前置**：公共列、来源标记列、类型口径、枚举 `E{n}`、追加型豁免见《字段级数据字典-00-公共约定.md》。
> **来源依据**：技术规约 §4.7.4【强制】「营销触达必须内置频控与退订机制，退订名单全局生效——合规是产品底线」；「客服多渠道统一会话模型（渠道/会话 ID/客户 ID/坐席或 AI 主体），AI 转人工必须保留上下文」。
> **范围声明**：本文件仅承载 **P0-4 合规必需的 4 组表骨架**（退订 / 频控 / 统一会话 + 关联消息；账号资产归 L1 见 02 §1.4）。**营销(`mkg_`)/客服(`svc_`) 完整业务建模在 Wave 3 第二批扩写本文件**，本处「可先只建表 + 审计列，业务规则后续填」（清单 P0-4 交付物口径）。
> **红线冻结**：退订「全局生效」跨租户 vs 租户内 → 待 Wave 0 ⑤/⑦（ADR-0004）；相关唯一索引前缀与 RLS 标记裁决前不出 DDL。

## 一、统一会话（`svc_`·客服三条线共用）　P0-4③

### 1.1 `svc_session` · 会话主表
> 租户:是｜RLS:是｜来源:是（AI 主体写入，双通道同源）｜分区:否（活跃会话；终态归档另行）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `session_no` | `VARCHAR(64)` | `NOT NULL` | 会话业务号 |
| `channel_type` | `VARCHAR(16)` | `NOT NULL` | E51 |
| `external_conv_id` | `VARCHAR(128)` | | 渠道侧会话/线程 ID（多平台映射） |
| `biz_scene` | `VARCHAR(16)` | `NOT NULL` | E53（询盘/接待/售后三条线共用一张） |
| `customer_id` | `BIGINT` | | → `cus_customer`（识别后回填） |
| `entity_id` | `BIGINT` | | → `dt_entity_company`（未落客户前的实体态） |
| `lead_id` | `BIGINT` | | → `cus_lead` |
| `status` | `VARCHAR(16)` | `NOT NULL` | E52 |
| `ai_actor_code` | `VARCHAR(64)` | | 当前 AI 主体智能体编码（`source_type=AGENT` 时） |
| `assigned_user_id` | `BIGINT` | | 当前坐席（转人工后回填 `sys_user.id`） |
| `handover_flag` | `BOOLEAN` | `NOT NULL default false` | 是否已 AI→人工（上下文保留） |
| `handover_reason` | `TEXT` | | 接管原因（对应前端 `<LxTakeoverButton>`，强制填写） |
| `last_msg_at` | `TIMESTAMPTZ` | | 最近一条消息时刻 |
| `closed_at` | `TIMESTAMPTZ` | | |

索引：`UNIQUE(tenant_id, session_no) WHERE is_deleted=0`、`(tenant_id, customer_id, last_msg_at)`、`(tenant_id, status, biz_scene)`、`(channel_type, external_conv_id)`。

### 1.2 `svc_session_message` · 会话消息明细
> 租户:是｜RLS:是｜来源:是｜**追加型**（见 00 §一·附）｜分区:是（按月 `msg_at`）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `session_id` | `BIGINT` | `NOT NULL` | → `svc_session.id` |
| `seq_no` | `INTEGER` | `NOT NULL` | 会话内序号（保序/上下文回放） |
| `direction` | `VARCHAR(8)` | `NOT NULL` | E54（入站/出站） |
| `content_type` | `VARCHAR(16)` | `NOT NULL` | `TEXT` / `IMAGE` / `FILE` / `CARD` |
| `content` | `JSONB` | `NOT NULL` | 消息体（多语言/富文本；引用 `sys_file` 存二进制） |
| `ai_generated` | `BOOLEAN` | `NOT NULL default false` | 是否 AI 产出（前端 `<LxAgentSourceTag>` 标记） |
| `sender_ref` | `VARCHAR(64)` | | 发送主体标识（客户 / 坐席 / 智能体编码） |
| `msg_at` | `TIMESTAMPTZ` | `NOT NULL` | 分区键 |

索引：`UNIQUE(tenant_id, session_id, seq_no)`、`(session_id, msg_at)`。

## 二、营销触达合规（`mkg_`）　P0-4①②

### 2.1 `mkg_unsubscribe` · 退订名单
> 租户:待裁决（🔴「全局生效」跨租户 vs 租户内 → 待 Wave 0 ⑤/⑦）｜RLS:待裁决｜来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `channel_type` | `VARCHAR(16)` | `NOT NULL` | E51 |
| `target_type` | `VARCHAR(16)` | `NOT NULL` | E56 |
| `target_value` | `VARCHAR(256)` | `NOT NULL` | 退订目标（邮箱/号码；敏感值可哈希存储，见 05-security） |
| `target_norm` | `VARCHAR(256)` | `NOT NULL` | 规范化值（小写邮箱等），用于全局强匹配 |
| `source_campaign_id` | `BIGINT` | | 触发退订的活动（Wave 3 建 `mkg_campaign` 后补外键） |
| `reason` | `VARCHAR(256)` | | 退订原因 |
| `unsubscribed_at` | `TIMESTAMPTZ` | `NOT NULL` | |

索引（🔴 冻结，随裁决二选一）：
- 若「全局跨租户」：`UNIQUE(channel_type, target_norm)`（免租表，全平台去重）；
- 若「租户内」：`UNIQUE(tenant_id, channel_type, target_norm)` + RLS。
> **验收**：退订名单须能被触达链路**强校验**（发送前查此表命中即拦截）；「全局生效」口径待 ⑤/⑦。

### 2.2 `mkg_freq_rule` · 频控规则（配置）
> 租户:是｜RLS:是｜来源:否｜分区:否

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `channel_type` | `VARCHAR(16)` | `NOT NULL` | E51 |
| `period` | `VARCHAR(8)` | `NOT NULL` | E55 |
| `max_count` | `INTEGER` | `NOT NULL` | 每「客户 × 渠道 × 周期」上限 |
| `scope` | `VARCHAR(16)` | `NOT NULL` | `CUSTOMER` / `ENTITY` / `MARKET`（计数维度） |
| `is_active` | `BOOLEAN` | `NOT NULL default true` | |

索引：`UNIQUE(tenant_id, channel_type, period, scope) WHERE is_deleted=0`。

### 2.3 `mkg_freq_counter` · 频控计数账本（对账）
> 租户:是｜RLS:是｜来源:否｜分区:是（按月 `period_key` 起点）
> **说明**：实时限次计数走 **Valkey**（总览§八：计数/限流），本表为**落库对账/审计快照**，由消费侧周期回写，避免高频 UPDATE 争用。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `rule_id` | `BIGINT` | `NOT NULL` | → `mkg_freq_rule.id` |
| `target_type` | `VARCHAR(16)` | `NOT NULL` | `CUSTOMER` / `ENTITY` |
| `target_id` | `BIGINT` | `NOT NULL` | 计数对象 |
| `channel_type` | `VARCHAR(16)` | `NOT NULL` | E51 |
| `period_key` | `VARCHAR(16)` | `NOT NULL` | 周期桶（如 `2026-09-11D`、`2026-37W`） |
| `hit_count` | `INTEGER` | `NOT NULL default 0` | 该周期已触达次数 |

索引：`UNIQUE(tenant_id, rule_id, target_type, target_id, channel_type, period_key)`、`(target_type, target_id, period_key)`。
