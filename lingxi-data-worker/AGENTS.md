# AGENTS.md · lingxi-data-worker（数据任务，一期空缺）

> 总纲见仓库根级 `../AGENTS.md`（本文件冲突时以根级为准）。

## 状态：一期空缺

一期数据任务（采集 / 清洗 / 实体消歧 / 指标计算）由 `lingxi-server` 内的
`lingxi-data-jobs` 进程承载（见 ADR-0003）。本仓库为占位，暂不启用。

## 若启用（需先开 ADR）

1. **独立 CI 流水线**：与后端 Java 链路分属两套构建，不得混用同一条流水线。
2. **禁止承载业务逻辑**：业务链路的唯一语言栈是 Java（已确认原则）；本仓只做数据采集与算法。
3. **数据不落地本地**：连云端数据服务，经 SSH 隧道（与后端同一套隧道定义）。
4. 与业务交互一律经 `lingxi-data` 暴露的 API 或事件，禁止直连业务库改数据。
