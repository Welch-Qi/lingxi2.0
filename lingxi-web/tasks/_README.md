# tasks/ · 任务简报

> 本目录存放派发给 AI Coding 工具的任务简报，命名 `M{模块}-{类型}.md`
> （类型：`DEV` / `TEST` / `FIX` / `DOC`）。

## 简报必须包含

| 段落 | 内容 |
|---|---|
| 任务号 | 如 `M0202-001`，与根级 `TASKS.md` 一致 |
| 目标 | 一句话说清「做什么」，不要写「优化一下」这类无法验收的表述 |
| 边界 | 明确允许改哪些文件/目录；**永不包含** `lingxi-docs/01-product`~`05-security` 与 `config/` |
| 依赖 | 前置任务号 / 已有接口 / 需先更新的契约 |
| 验收标准 | 可执行的判据（测试命令、接口返回、页面行为），而非主观描述 |
| 待决策 | 遇到歧义时记录在此，**不要自行定规矩** |

## 铁律

1. **无简报不派发**——AI 不得自行扩大范围。
2. 简报由协调 Agent 产出；AI 工具只读。
3. 需求变更改简报，不改派发逻辑。
